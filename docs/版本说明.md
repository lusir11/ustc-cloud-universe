日常开发使用本地 `main` 分支。团队仓库对应远端 `origin`，个人仓库对应 `personal`。下列标签标记本次整理时保留的版本。

| Git 标签 | 提交 | 内容 |
| --- | --- | --- |
| `campus-baseline-20261118` | `0072230` | 11 月 18 日本地克隆的校园基线。 |
| `campus-team-20261124` | `1ceb600` | 11 月 24 日取得的团队主线，包含人文楼和校园人物等更新。 |
| `campus-art-20261124` | `1ea00ba` | 在团队主线上加入图书馆写实样景、美术规范、分区图和核对资料。 |

在仓库根目录运行 `git log --oneline --decorate main` 可以查看提交顺序。比较本地美术工作可运行 `git diff --stat campus-team-20261124 campus-art-20261124`。后续开发直接在 main 提交，里程碑可继续添加带说明的标签。
