# 体育教学部与新人文楼实景建模

从南区体育场附近的东侧道路向西走，可以穿过玻璃连桥下方，到楼后沿步道向南走到球场。在 Windows 上双击 [OPEN_HUMANITIES.cmd](../OPEN_HUMANITIES.cmd) 可以直接从人文楼前开始漫游。

## 当前游戏模型

校园场景按白底 Blender 定稿放置整栋人文楼。标有“人文楼”的入口面向东侧道路，玻璃连桥下方的车廊东西贯通，通道两旁各停八辆电单车。西侧后翼和体育教学部北门沿用原场地，北门三级台阶与前院相连。体育教练位于北门外。

[建筑游戏模型](../campus/godot/assets/models/humanities_replica.glb)与[陈设和碰撞布局](../campus/godot/assets/models/humanities_replica_layout.json)共用模型的本地米制坐标。[本版实机截图与通行检查](../campus/renders/pe_humanities/replica/)覆盖道路、前后洞口和廊下停车区。

在 Blender 中打开[人文楼源文件](../campus/blender/pe_humanities/humanities_replica.blend)，可以查看透明幕墙、窗后的室内空间和贯通的首层车廊。[多机位渲染与盲审记录](../campus/renders/pe_humanities/replica/blender/)包含五张正交图、入口和庭院近景，以及连廊修改前后的对照图。[人文楼与校园男生制作工作流](<人文楼与校园男生制作工作流（含 Shift 日常跑）.pptx>)第 4 页收录了五张正交图。

演示中的校园男生有独立的 [Blender 源文件](../campus/blender/source/campus_student.blend)。重新导出角色时，使用 NLA Tracks 导出五组动作，再用[跑步动作重定向脚本](../campus/blender/scripts/retarget_jog.py)将 [KinemIQ 发布的 CC0 日常跑](https://github.com/Kinemiq/free-game-animations/releases/tag/v1.0)写入 `run`。最终的[游戏角色](../campus/godot/assets/campus_student.glb)已包含这一动作。

## 早期实景模型

1. 对照体育教学部的 6 张照片和新人文楼的 13 张照片。体育教学部的东西立面与新人文楼 B 楼照片对应，按同一楼体建模。A、B 楼间的玻璃连廊以东侧实拍为准，A、C 楼之间的院落和连接处另行建模。
2. 用 Codex 生图整理[白底体量图](../campus/renders/pe_humanities/白底体量推演.jpg)及[多视角图](../campus/renders/pe_humanities/多视角推演.jpg)，用来检查体块关系。实拍与生成图有出入时以实拍为准。楼体平面参照 OSM，标高、立面进深及幕墙开口按照片估算。
3. 建立可编辑的 [Blender 场景](../campus/blender/pe_humanities/pe_humanities.blend)，将模型、铺装和碰撞接入 Godot 校园。B 楼北门保留三级台阶与侧边花池；A 楼保留砖框上方的透空；C 楼按照片表现博物馆和 C101、C102 门面。
4. 独立审查者对照多个游戏机位与实拍。复核后将桥下改为硬质铺装，接通北门前道路，将花池移到台阶侧边，并抬高 A 楼东侧幕墙上沿。

## 早期模型实机验收

[九个机位的游戏截图](../campus/renders/pe_humanities/)与[逐项验收结果](../campus/renders/pe_humanities/checks.json)对应同一份游戏模型。验证包括桥下约 40 米东西双向通行、中庭约 18 米双向通行、北门三级台阶和两翼墙体的阻挡。桥下模型净高约 3.92 米。已验证的步行范围在地面层，楼上连廊为外观模型。
