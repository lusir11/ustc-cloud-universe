运行样景使用完整校园工程。旧轮次的脚本与材质保存为历史快照，通过 .gdignore 隔离编辑器导入。复现早期制作流程时，按对照表恢复相应轮次的目录和文件，并按本机位置调整脚本内的历史路径。团队现行分工使用项目模型俯视图。根据项目源码运行说明，原始研究影像及含这些影像的对照图只在本地留档。使用本地图面比对页时，请先准备表中标为“本地地图参考”的配套图片。地图参考来自 https://map.ustc.edu.cn/ 和 Esri World Imagery。日志和临时地图裁图仅在原工作区保留。
