# CB10 新人文楼复刻盲审

独立审查员对照建筑多视图、现场照片、Blender 白底渲染和 Godot 校园实拍进行四轮目视审查。最终版通过。白底全景便于看清被邻楼遮挡的 B 楼弧端，通行与碰撞均在实际校园场景中验证。

| 机位 | 复核结果 |
| --- | --- |
| 东院门正视与斜俯视 | 两块白牌均朝东。面向院内，左侧为科技人文高等研究院，右侧为人文与社会科学学院。牌外分别有两根、五根无牌砖柱。入口铺地接到校园道路。 |
| 东侧校徽与悬窗 | 徽章后方有错缝透空砖屏。玻璃悬窗底部架空，角色可由东口进入，向北转入 A、B 楼之间的通道。 |
| 中庭玻璃门厅 | 从东往西看，左侧 C 楼低，右侧 A 楼高。两层高的玻璃门厅位于院落西端。下层双扇门、上部题字和左侧地面校牌可见。 |
| C 楼临院入口 | 对应原始照片，C101 为浅色双拼石坡，C102 为短台阶，钱邻照科学史博物馆为玻璃双门和跨过相邻砖墙的宽台阶。 |
| 屋顶与建筑全景 | 正俯视可对照平行楼翼、院落、玻璃连接段与屋顶设备。B 楼入口旁的砖柱、侧坡道和局部台阶依体育教学部实拍保留。 |

首轮发现徽章格栅、沿墙植栽与院门来路表现不足。第二轮的白底东视图揭示玻璃悬窗下方受实体墙遮挡。第三轮拆通后复查了地面路线，随后细化 C 楼爬藤和 C101 坡板拼缝。第四轮复核了这些近景与整栋布局。

完整游戏验证通过 18 项场景、通行与碰撞检查，以及 9 项固定机位截图检查。生成的模型与检查报告使用同一 SHA-256。回归程序以状态码 0 退出，退出阶段有渲染资源释放警告。[逐项结果](checks.json)

仍可从照片辨出局部差异。实拍 C102 的垂藤更密，石板纹理变化更多，门窗内景和桥下远端也比当前校园光照下更亮。[最终独立视图](../../../data/建筑/CB10_新人文楼／人文与社会科学学院/多视图/模型复刻验收/)
