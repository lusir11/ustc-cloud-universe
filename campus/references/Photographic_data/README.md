# 科大东区采集资料库

建筑和场景可从 [点位索引](点位索引.csv) 中按编号或名称查找。进度中的「有资料」表示已有相应的文件。

| 目录                                           | 存放内容                           |
| ---------------------------------------------- | ---------------------------------- |
| `建筑/编号_名称/照片/`、`场景/编号_名称/照片/` | 对应点位的实地拍摄照片             |
| `公共素材/`                                    | 可在多处复用的贴图、模型和校园地图 |

- 照片按 `建筑或场景名-具体位置-拍摄方位` 命名，例如 `新人文楼-A楼C楼连接处-东侧`。
- 同一位置、同一角度补拍时，在扩展名前续加序号，例如 `新人文楼-A楼C楼连接处-东侧-01`、`新人文楼-A楼C楼连接处-东侧-02`，下一张接 `-03`。
